# Pronunciation Coach — User Guide

## What is this?

Pronunciation Coach helps you improve two skills:

- **Pronunciation** — producing the correct individual sounds (phonemes)
- **Articulation** — speaking clearly with good pacing, stress, and rhythm

It supports **French** and **English** with targeted exercises and detailed feedback powered by Azure Speech.

## Core Loop

1. Choose an exercise (by language, track, focus sound, or difficulty)
2. Listen to the native reference (text-to-speech)
3. Record yourself saying the text
4. Receive scores:
   - Per-phoneme accuracy (color coded)
   - Overall pronunciation score
   - Articulation / prosody feedback (rate, pauses, stress)
5. Review your attempt vs the reference
6. Drill weak sounds or advance speed ladders

## Exercise Tracks

- **Phoneme accuracy** — Focus on specific sounds with minimal pairs, loaded sentences, passages
- **Articulation** — Tongue twisters and clusters practiced at increasing speeds
- **Prosody** — Rhythm, stress, liaison, shadowing the reference

## Progress

- Weak-sound engine automatically surfaces sounds you struggle with most
- Speed ladders unlock higher tempos only after you hit accuracy targets
- Charts show your improvement over time

## Tips for Best Results

- Speak at a natural but clear pace
- Use a quiet environment
- Headphones + good mic help
- Repeat difficult items immediately

## Limitations (v1)

- Single user, local data only
- Requires internet for Azure scoring and TTS
- Azure free tier quota applies (personal use is fine)
- No offline mode
